# Career Compass

Build a production-ready Android app called “Career Shield – Job Security & AI Survival Planner”.

App goal:
Help users understand job insecurity, skill gaps, and AI impact through educational self-assessment tools. This app does NOT provide job guarantees or professional advice.

Target users:
Students, fresh graduates, contract workers, and professionals worried about layoffs and AI.

Core features:
1. Job Risk Analyzer
- Input: industry, job role, contract type, experience level, location, automation exposure
- Output: Low / Medium / High risk with clear educational explanations
- Include disclaimer that results are informational, not predictive

2. Skill Gap Checker
- Compare current skills with future-relevant skills
- Show transferable skills and gaps
- No external API required

3. Career Survival Planner
- Personalized short, mid, and long-term plans
- Focus on skills, habits, and career flexibility
- Educational guidance only

4. AI Job Exposure Tool
- Score how exposed a job is to automation
- Explain why
- Suggest human-centric skills to reduce risk

5. Progress Tracking
- Save assessments and progress using LocalStorage
- Offline-first
- No login, no backend

Monetization structure:
- Free version with basic insights
- Premium unlock for advanced analysis, comparisons, and detailed reports
- Do NOT include ads in this build

Design:
- Clean, modern, professional
- Calm colors (blue/green)
- Simple icons
- Minimal text overload

Compliance:
- Clearly state educational purpose
- No promises of employment or income
- Play Store safe language

Output a polished, scalable Android app template ready for further development in Android Studio.
